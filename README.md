# Ayush Kumar — Data Analyst Portfolio

A responsive personal portfolio showcasing Ayush Kumar's data analytics skills, selected projects, education, and contact links.

## Features

- Single-page layout with About, Skills, Projects, Education, and Contact sections
- Responsive styling with Tailwind CSS and custom CSS
- Animated data-themed visuals powered by Three.js
- Interactive skills and project cards rendered with JavaScript
- Resume link to `Ayush_Kumar.pdf`

## Tech Stack

- HTML, CSS, and vanilla JavaScript
- [Tailwind CSS Play CDN](https://tailwindcss.com/docs/installation/play-cdn)
- [Three.js](https://threejs.org/) r128
- Google Fonts: Inter and Space Grotesk

The CSS framework, 3D library, and fonts are loaded from external CDNs, so an internet connection is needed for the complete visual experience.

## Run Locally

No build step or package installation is required. Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/ayushsingh76/ayush-kumar-portfolio.git
cd ayush-kumar-portfolio
```

You can also serve the folder with any static file server. For example, with Python:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
